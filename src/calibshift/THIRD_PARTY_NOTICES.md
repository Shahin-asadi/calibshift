# Code and data provenance

The numerical packages listed in pyproject.toml retain their own licenses. No paper figures, PDF texts or unpublished measurements are distributed. The bundled processed public examples retain CC BY 4.0; see DATA_SOURCES.json and the preparation notes. The MIT license covers this project's software, not a replacement license for those datasets.

The two portfolios share locally developed input, PLS preprocessing and report utilities, vendored so each project runs independently. Their scientific analyses and tests serve different questions. No upstream research implementation was copied into these utilities.
